## 3. データモデル

### 3-1. FriendRequest（友達申請）

```dart
class FriendRequest {
  final String requestId;       // ドキュメントID
  final String fromUid;         // 申請を送ったユーザーの UID
  final String toUid;           // 申請を受け取ったユーザーの UID
  final FriendRequestStatus status; // pending | accepted | declined
  final DateTime createdAt;
}

enum FriendRequestStatus { pending, accepted, declined }
```

### 3-2. Friend（友達関係）

```dart
class Friend {
  final String friendshipId;    // ドキュメントID
  final List<String> userIds;   // 常に2人の UID [uid_A, uid_B]
  final DateTime createdAt;     // 友達になった日時
}
```

### 3-3. Group（グループ）

```dart
class Group {
  final String groupId;
  final String name;
  final String ownerUid;
  final List<GroupMember> members;  // オーナー含む最大5人
  final DateTime createdAt;
  final DateTime updatedAt;
}

class GroupMember {
  final String uid;
  final GroupRole role;           // owner | member
  final GroupMemberStatus status; // invited | joined
  final DateTime joinedAt;
}

enum GroupRole { owner, member }
enum GroupMemberStatus { invited, joined }
```

### 3-4. Box（変更）

```dart
class Box {
  // 既存フィールドに以下を追加

```

### 3-5. AppNotification（アプリ内通知）

```dart
class AppNotification {
  final String notificationId;
  final String toUid;                   // 通知先ユーザーの UID
  final NotificationType type;          // 通知の種類
  final String title;                   // 通知タイトル
  final String body;                    // 通知本文
```

## 5. ユーザーQRコードの仕様

封印物のQRコードと区別するため、ユーザーQRは専用のフォーマットを使用する。

```
fujin-user://{uid}
例: fujin-user://xK9mZ3aQ2pLvBn7R
```

- アプリ内でQRを読み取ったとき、`fujin-user://` プレフィックスを検出したらユーザーQRとして処理する
- `fujin://` プレフィックスなら封印QRとして処理する（既存動作）
- 既存の `QRCodeUtils` に `isUserQR(String qrCode)` と `extractUidFromUserQR(String qrCode)` を追加する

## 6. 招待リンクの仕様

```
https://fujin.app/invite?from={uid}&token={token}&expires={timestamp}
```

| パラメータ | 内容 |
|-----------|------|
| `from` | 招待を送ったユーザーの UID |
| `token` | ランダム生成トークン（Firestore に保存して照合） |
| `expires` | 有効期限（UTC タイムスタンプ。72時間後） |

- リンクを開くとアプリが起動し、`from` の uid から送信者情報を取得して申請確認画面を表示する
- `token` が存在しない・期限切れ・使用済みの場合はエラーを表示する
- 承認後に `token` を無効化する

**実装方針**：`uni_links` パッケージでディープリンクを処理する。Firebase Dynamic Links は2025年8月に廃止済みのため使用しない。

## 7. Firebase Cloud Messaging（プッシュ通知）

### アーキテクチャ

```
Firestoreへ書き込み（notifications コレクション）
  ↓
Cloud Functions（onDocumentCreated トリガー）
  ↓
FCM で対象ユーザーへプッシュ通知送信
```

- FCM トークンは `users/{uid}/fcmToken` として Firestore に保存する
- アプリ起動時・トークン更新時に Firestore を更新する
- `fcm_service.dart` でトークン取得・更新・通知受信ハンドリングを担う

### Cloud Functions の配置

```
functions/
  index.js (or index.ts)
    ├── onNotificationCreated: notifications/{id} の作成をトリガー
    └── （将来）onFriendRequestCreated 等
```

> Cloud Functions は本リポジトリとは別管理（Firebase コンソールまたは `functions/` ディレクトリ）。Phase 1.2 では最小限の1関数のみ実装する。

### 8-4. 封印QRスキャンの連続読み取りフロー（UX改善）

Phase 1.0・1.1 では「1回のスキャンで1枚読み取り → 自動pop → 再度カメラを開く」という操作だったが、Phase 1.2 で連続スキャンに改善した。

#### 変更前（Phase 1.0・1.1）

```
[封印画面]
  「QRをスキャン」タップ
  │
  └── Navigator.push → SealQRScanPage
        ├── QR検出 → バリデーション → onQRScanned コールバック
        ├── 成功フィードバック表示
        └── 1秒後に自動 Navigator.pop()  ← 毎回カメラが閉じる
  ↓
  （2枚目を読みたい場合、再度「QRをスキャン」をタップ）
```

#### 変更後（Phase 1.2）

```
[封印画面]
  「QRをスキャン」タップ
  │
  └── Navigator.push → SealQRScanPage（連続スキャンモード）
        │
        ├── QR検出 → バリデーション → 内部の _sessionScannedCodes に蓄積
        │     ├── 成功 → Face ID チップをリアルタイム表示（カメラ閉じない）
        │     └── エラー → エラーメッセージ2秒表示（カメラ閉じない）
        │
        ├── 2枚目、3枚目... → 同じカメラセッションで連続読み取り
        │
        └── ユーザーが「スキャン完了」ボタンをタップ
              └── SealQRScanResult を Navigator.pop() で返却
                    ├── scannedCodes: Map<String, String>（faceId → qrCode）
                    └── boxId: String?
  ↓
  封印画面で SealQRScanResult を受け取り、scannedQRCodes に一括追加
```

#### SealQRScanResult データクラス

```dart
class SealQRScanResult {
  final Map<String, String> scannedCodes;  // faceId → qrCode
  final String? boxId;
}
```

#### UI構成

| 要素 | 位置 | 内容 |
|------|------|------|
| ✕ ボタン | 左上 | タップで画面を閉じる（読み取り済み分は保持して返却） |
| タイトル | 上部中央 | 「QRコードをスキャン」 |

## 9. Firestore Security Rules の変更

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // 既存: boxes（groupId 参照追加・開封権限制限追加）
    match /boxes/{boxId} {
      allow get: if request.auth != null;
      allow list: if request.auth != null;

      // 削除: オーナーのみ
      allow delete: if request.auth != null
                    && request.auth.uid == resource.data.metadata.userId;

      // 更新:
      //   - 個人箱（groupId が null）: オーナーのみ
      //   - グループ共有箱: オーナー または そのグループのメンバー
      //   ※開封操作（status の更新）もこのルールで制御される
      allow update: if request.auth != null
                    && (
                      request.auth.uid == resource.data.metadata.userId
                      || (
                        resource.data.metadata.groupId != null
                        && request.auth.uid in get(/databases/$(database)/documents/groups/$(resource.data.metadata.groupId)).data.members
                      )
                    );

      allow create: if request.auth != null
                    && request.resource.data.metadata.userId == request.auth.uid;
    }

    // 友達申請
    match /friend_requests/{requestId} {
      allow read: if request.auth != null
                  && (request.auth.uid == resource.data.fromUid
                      || request.auth.uid == resource.data.toUid);
      allow create: if request.auth != null
                    && request.resource.data.fromUid == request.auth.uid;
      allow update: if request.auth != null
                    && request.auth.uid == resource.data.toUid;
    }

    // 友達関係
    match /friendships/{friendshipId} {
      allow read, delete: if request.auth != null
                          && request.auth.uid in resource.data.userIds;
      allow create: if request.auth != null
                    && request.auth.uid in request.resource.data.userIds;
    }

    // グループ
    match /groups/{groupId} {
      allow read: if request.auth != null
                  && request.auth.uid in resource.data.members;
      allow create: if request.auth != null
                    && request.resource.data.ownerUid == request.auth.uid;
      allow update: if request.auth != null
                    && request.auth.uid == resource.data.ownerUid;
      allow delete: if request.auth != null
                    && request.auth.uid == resource.data.ownerUid;
    }

    // 通知（自分宛のみ読み書き可能）
    match /notifications/{notificationId} {
      allow read, update: if request.auth != null
                          && request.auth.uid == resource.data.toUid;
      allow create: if request.auth != null;  // アプリからの書き込みを許可
    }
  }
}
```
