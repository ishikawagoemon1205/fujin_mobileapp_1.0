# 封神(Fujin) QRコード仕様 - 完全版

## QRコードフォーマット
```
fujin://{box-id}/{face-id}/{checksum}
```

## 各要素の詳細仕様

### 1. box-id (8文字固定)
- **文字セット**: Base62 = `0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ`
- **長さ**: 必ず8文字
- **生成方法**: ランダムにBase62文字を8個選択
- **例**: `B7K9M3X2`, `A1C4E8F2`, `zY9x8W7v`

### 2. face-id
- **フォーマット**: `F` + 数字(1桁の場合) または `F` + Base62文字(2桁以上の場合)
- **範囲**: 
  - F1, F2, F3, F4, F5, F6, F7, F8, F9 (1〜9面)
  - FA, FB, FC, ..., FZ (10〜35面)
  - Fa, Fb, Fc, ..., Fz (36〜61面)
  - F0 (62面目)
- **通常使用**: F1〜F6 (箱の6面分)

### 3. checksum (4文字固定)
- **アルゴリズム**: CRC-16
- **入力**: `{box-id}{face-id}` を連結した文字列
- **出力**: 16進数大文字4桁 (例: `A3C9`, `B8D1`, `0F2E`)
- **重要**: 必ず大文字、必ず4桁(先頭0埋め)

## 実装例 (TypeScript/JavaScript)

### 必須パッケージ
```bash
npm install crc
```

### box-id生成
```typescript
const BASE62_CHARS = '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ';

function generateBoxId(): string {
  let result = '';
  for (let i = 0; i < 8; i++) {
    const randomIndex = Math.floor(Math.random() * BASE62_CHARS.length);
    result += BASE62_CHARS[randomIndex];
  }
  return result;
}
```

### face-id生成
```typescript
function generateFaceId(index: number): string {
  if (index < 1 || index > 62) {
    throw new Error('Face index must be between 1 and 62');
  }
  
  if (index <= 9) {
    return `F${index}`;
  }
  
  // 10以降: FA, FB, ..., FZ, Fa, Fb, ..., Fz, F0
  const base62Index = index - 10;
  const char = BASE62_CHARS[base62Index + 10]; // Skip '0'-'9'
  return `F${char}`;
}
```

### checksum生成 (重要!)
```typescript
import { crc16 } from 'crc';

function generateChecksum(boxId: string, faceId: string): string {
  const input = boxId + faceId; // 例: "B7K9M3X2F1"
  const crcValue = crc16(input);
  return crcValue.toString(16).toUpperCase().padStart(4, '0');
}
```

### 完全なQRコード生成
```typescript
function generateQRCode(boxId: string, faceIndex: number): string {
  const faceId = generateFaceId(faceIndex);
  const checksum = generateChecksum(boxId, faceId);
  return `fujin://${boxId}/${faceId}/${checksum}`;
}

// 使用例
const boxId = generateBoxId(); // 例: "B7K9M3X2"
const qr1 = generateQRCode(boxId, 1); // "fujin://B7K9M3X2/F1/A3C9"
const qr2 = generateQRCode(boxId, 2); // "fujin://B7K9M3X2/F2/B8D1"
const qr3 = generateQRCode(boxId, 3); // "fujin://B7K9M3X2/F3/C2E7"
```

## 検証方法

### 正規表現パターン
```typescript
const QR_PATTERN = /^fujin:\/\/[0-9a-zA-Z]{8}\/F[0-9a-zA-Z]\/[0-9A-F]{4}$/;

function validateQRFormat(qrCode: string): boolean {
  return QR_PATTERN.test(qrCode);
}
```

### checksum検証
```typescript
function validateChecksum(qrCode: string): boolean {
  const match = qrCode.match(/^fujin:\/\/([0-9a-zA-Z]{8})\/(F[0-9a-zA-Z])\/([0-9A-F]{4})$/);
  if (!match) return false;
  
  const [, boxId, faceId, providedChecksum] = match;
  const expectedChecksum = generateChecksum(boxId, faceId);
  
  return providedChecksum === expectedChecksum;
}
```

## 実際の例

### 正しい例
```
fujin://B7K9M3X2/F1/A3C9  ✅
fujin://A1C4E8F2/F2/B8D1  ✅
fujin://zY9x8W7v/F6/0F2E  ✅
fujin://12345678/FA/C4D9  ✅ (10面目)
```

### 間違った例
```
fujin://B7K9M3X/F1/A3C9   ❌ (box-idが7文字)
fujin://B7K9M3X2/1/A3C9   ❌ (face-idに"F"がない)
fujin://B7K9M3X2/F1/a3c9  ❌ (checksumが小文字)
fujin://B7K9M3X2/F1/A3C   ❌ (checksumが3文字)
FUJIN://B7K9M3X2/F1/A3C9  ❌ (スキーマが大文字)
```

## よくある間違い

1. **checksumの大文字小文字**: 必ず大文字で出力すること
2. **checksumの桁数**: 必ず4桁(先頭0埋め)、例: `0F2E` (×`F2E`)
3. **face-idの形式**: F1, F2, ..., F9, FA, FB, ... (×F01, F02)
4. **box-idの長さ**: 必ず8文字 (×7文字や9文字)
5. **スキーマ**: `fujin://` (小文字) (×`Fujin://`, ×`FUJIN://`)

## CRCライブラリの注意点

### Node.js (推奨)
```typescript
import { crc16 } from 'crc'; // npmパッケージ 'crc'
const checksum = crc16('B7K9M3X2F1').toString(16).toUpperCase().padStart(4, '0');
```

### 他のCRCライブラリを使う場合
- **アルゴリズム**: CRC-16 (多くのバリエーションがあるので注意)
- **モバイルアプリ側**: Dart `crc` パッケージの `Crc16()` を使用
- **互換性確保**: 同じ入力で同じ出力が得られることをテストで確認

## テスト用データ

以下のQRコードで動作確認してください:

```typescript
// テストケース1
const boxId1 = "TEST0001";
const qr1_1 = generateQRCode(boxId1, 1); // face F1
const qr1_2 = generateQRCode(boxId1, 2); // face F2

// テストケース2
const boxId2 = "ABC12xyz";
const qr2_1 = generateQRCode(boxId2, 1);
const qr2_2 = generateQRCode(boxId2, 2);

// 検証
console.assert(validateQRFormat(qr1_1), "Format validation failed");
console.assert(validateChecksum(qr1_1), "Checksum validation failed");
```

モバイルアプリ側でこれらのQRコードがスキャンできることを確認してください。

## デバッグ用ツール

```typescript
function debugQRCode(qrCode: string) {
  console.log("QR Code:", qrCode);
  console.log("Format Valid:", validateQRFormat(qrCode));
  
  const match = qrCode.match(/^fujin:\/\/([0-9a-zA-Z]{8})\/(F[0-9a-zA-Z])\/([0-9A-F]{4})$/);
  if (match) {
    const [, boxId, faceId, checksum] = match;
    console.log("Box ID:", boxId, "(length:", boxId.length, ")");
    console.log("Face ID:", faceId);
    console.log("Checksum:", checksum);
    
    const expectedChecksum = generateChecksum(boxId, faceId);
    console.log("Expected Checksum:", expectedChecksum);
    console.log("Checksum Match:", checksum === expectedChecksum);
  }
}
```

この仕様に厳密に従ってQRコードを生成してください。
